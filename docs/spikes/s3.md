# Спайк S3: Плотность Street View, распределение регионов и квоты Google API

Дата: 2026-11-13
Цель: проверить алгоритм взвешенного выбора стран без повторов в рамках матча, расчёт диагоналей регионов (D) по Natural Earth 110m и ограничения бесплатных квот Google Maps Platform.

## 1. Взвешивание стран (`area^0.65`) и данные Natural Earth 110m

Генератор `scripts/build-regions.ts` обрабатывает `world-atlas/countries-110m.json`:

- Исключена Антарктида (`010`).
- Россия разделена по `60°E` на `europe` и `asia`; Французская Гвиана отнесена к `south_america`.
- Для 175 стран заполнены русские названия (`NAME_RU`).
- Диагональ $D$ вычисляется по минимальному охватывающему bbox с учётом пересечения 180-го меридиана (`world`, `asia`, `oceania`).

## 2. Порог 20+ стран в стране и fallback (120 км)

- Для регионов `world` (175), `africa` (51), `asia` (48) и `europe` (39) число доступных стран значительно превышает максимальное число раундов в матче (15), что гарантирует выбор без повторений.
- Для `south_america` (14) и `oceania` (7) при `rounds > countries.length` предусмотрен безопасный откат (после исчерпания уникальных стран разрешается повтор в рамках матча).
- Береговой/пограничный поиск `findCountryAtPoint(pos)` применяет допуск **120 км** по расстоянию до вершин полигона при неточном попадании у береговой линии.

## 3. Квоты Google Cloud Console и защита бюджета

По актуальным правилам Google Maps Platform (Essentials / free tier в месяц без списаний):

| Метрика                                     | Бесплатный порог Google / мес | Потолок в `quota.json` (`quotaCeilings`) | Рекомендуемый суточный лимит в Console |
| ------------------------------------------- | ----------------------------: | ---------------------------------------: | -------------------------------------- |
| Street View Static API (`staticRequests`)   |                        10 000 |                          **8 000** (80%) | 500 req/day                            |
| Street View Dynamic / JS Pano (`panoLoads`) |                         5 000 |                          **4 000** (80%) | 250 loads/day                          |
| Maps JavaScript API (`mapLoads`)            |                        10 000 |                          **8 000** (80%) | 500 loads/day                          |

При создании панорам и загрузке карт:

- Worst-case расчёт перед стартом матча проверяет все 3 счётчика с учётом числа игроков, ботов и раундов (`calculateWorstCaseMatchCost`).
- Браузер отчитывается по фактическим событиям `pano_loaded` и `map_loaded` (T53) при инициализации инстанса за матч.
- Фильтр `metadata` при выборе точки требует `status === 'OK'`, `source=outdoor` и наличие `Google` в `copyright` (исключает пользовательские фотосферы без панорамного графа Google).

## 4. Статус проверки с живым ключом Google (Gate владельца)

- Текущая переменная окружения `GOOGLE_API_KEY` в среде разработки возвращает `REQUEST_DENIED: This API is not activated on your API project`, а файл `.env` с `GOOGLE_MAPS_BROWSER_KEY` и `GOOGLE_MAPS_SERVER_KEY` ещё не настроен владельцем.
- **Что не удалось проверить без активации ключей:** живые вызовы `streetview/metadata`, реальную плотность уличного покрытия для 30 случайных семплов и прохождение 50-шагового графа `move` с живыми изображениями Street View Static API. Эти проверки выполняются сразу после добавления ключей и настройки ограничений в Google Cloud Console (`bun run doctor` + `bun run test:harness`).

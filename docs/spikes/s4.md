## Решение

**Своя сборка (Custom Build).** Ни один из открытых клонов не использует Svelte 5 + Bun, не реализует мультиплеер с ИИ-харнессами через MCP и дизайн-систему «асфальт и дорожная разметка» (`DESIGN.md`), а часть имеет несовместимые или отсутствующие лицензии. Экраны M1 строятся с нуля на Svelte 5 + Google Maps JS API.

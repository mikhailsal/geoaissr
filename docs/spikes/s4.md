# Spike S4: Survey of open-source GeoGuessr clones and license check

Date: 2026-11-13
Goal: assess whether ready-made screens/components can be borrowed for M1, or whether it is more reliable and faster to build the interface from scratch (the default is a custom build).

## Projects studied

| Project                   | Stack                                                   | License                                                   | Conclusion for geoaissr                                                                                                                    |
| ------------------------- | ------------------------------------------------------- | --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `codergautam/worldguessr` | Next.js / React + Node/Express + WebSocket              | **PolyForm Noncommercial 1.0.0**                          | Incompatible stack (React vs Svelte 5) and overloaded for a public portal (accounts, ratings, ads). The license is strictly noncommercial. |
| `daehli/earthwalker`      | Vue / Node / Docker, no Google key via public embedding | **GPL-3.0**                                               | Copyleft license (GPL-3.0) and a different panorama mechanism without the official Google API.                                             |
| `leny/Enigjewo`           | React + Maps JS API                                     | **ISC**                                                   | A learning single-player clone in React, without multiplayer, bots, MCP or Svelte 5.                                                       |
| `mesmerica/azimuth`       | Vanilla JS / HTML, single-player game                   | **No explicit license file found** (copyright by default) | Code cannot be borrowed without a license; no multiplayer, bots or tunnel.                                                                 |

## Decision

**Custom build.** None of the open-source clones uses Svelte 5 + Bun, implements multiplayer with AI harnesses over MCP, or the "asphalt and road markings" design system (`DESIGN.md`), and some have incompatible or missing licenses. The M1 screens are built from scratch on Svelte 5 + Google Maps JS API.

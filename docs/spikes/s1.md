# Спайк S1: Запуск ИИ-харнессов (`claude`, `codex`, `agy`), MCP, изоляция и конкурентность 3×5

Дата: 2026-11-13
Цель: проверить headless-запуск трёх локальных CLI (`claude`, `codex`, `agy`), передачу изображений через MCP или ограниченные локальные файлы, изоляцию от интернета/ФС/команд и стабильность при одновременном запуске 3 ботов в 5 раундах подряд (матрица 3×5).

## 1. Проверенные версии и флаги запуска

- `claude` (`2.1.323 (Claude Code)`):
  - Модель по умолчанию: `haiku`, reasoning `--effort <low|medium|high>`.
  - Передача изображений: `mcp` (в оперативной памяти через content-блоки `image/jpeg`).
  - Флаги изоляции: `--mcp-config <cfgPath> --strict-mcp-config --tools "" --allowedTools "mcp__geo__*" --permission-mode bypassPermissions --setting-sources "" --no-session-persistence --disable-slash-commands --output-format json`.
- `codex` (`codex-cli 0.167.0`):
  - Модель по умолчанию: `gpt-6-luna`, reasoning `-c model_reasoning_effort="<low|medium|high>"`.
  - Передача изображений: `mcp` (in-memory через `mcp_servers.geo`).
  - Флаги изоляции: `codex exec -m <model> -c web_search="disabled" -c features.apps=false -c features.shell_tool=false -c mcp_servers.geo.command=... -c mcp_servers.geo.args=... -c mcp_servers.geo.env.*=... -c mcp_servers.geo.tools.<tool>.approval_mode="approve" -s read-only --skip-git-repo-check --ephemeral --ignore-user-config --ignore-rules --json -C <workDir> -`.
- `agy` (`1.5.8`):
  - Модель по умолчанию: `gemini-3.8-flash-low`, reasoning `--effort <low|medium|high>`.
  - Передача изображений: **`file`** (эфимерная `workDir` на раунд, удаляемая после окончания раунда). При попытке режима `mcp` `agy` сбрасывает бинарные блоки в системную директорию, что требует чтения файла; режим `file` в `workDir` в сочетании с хуком `PreToolUse` решил одновременно задачу зрения и строгой изоляции.
  - Флаги изоляции: `--print=<prompt> --model <model> --effort <low|medium|high> --sandbox --disable-slash-commands --settings <workDir/settings.json> --output-format json` + плагин `.agents/plugins/geo/{plugin.json, mcp_config.json, hooks.json, guard.ts}`.
  - Хук `PreToolUse` (`guard.ts`): разрешает только MCP-инструменты `mcp_geo_geo_*` / `call_mcp_tool` (`geo_geo`) и чтение (`read_file` / `view_file`) строго внутри `realpathSync(workDir)` с исключением `.agents/`; отклоняет shell, веб-поиск, сторонние MCP и файлы вне `workDir`.
  - Примечание по `agy models`: команда `agy models` без CLI-авторизации возвращает `Please sign in to view available models`, поэтому адаптер пробует `agy models` и при ошибке безопасно использует список из `harnesses.json`.

## 2. Проверка изоляции (Canary-тесты)

Проверено с отключённым веб-поиском и канарными целями (`uname -a`, файл `/tmp/geoaissr-s1-canary.txt`):

- `agy` в режиме `file` + `guard.ts` успешно прочитал изображение в `workDir` и отклонил попытки чтения `/tmp/geoaissr-s1-canary.txt` и запуска `uname -a`.
- `claude` с `--tools ""` и `--strict-mcp-config` не имеет встроенных shell/FS/web-инструментов кроме `mcp__geo__*`.
- `codex` с `-s read-only`, `web_search="disabled"`, `features.shell_tool=false`, `--ignore-user-config --ignore-rules` работает строго через `mcp_servers.geo`.

## 4. Вывод для архитектуры

- Все три харнесса надёжно работают при параллельном запуске 3 ботов подряд в 5 раундах без утечки хост-файлов и без доступа к сети.
- Минимальный лимит времени раунда при наличии ИИ в настройках лобби обоснован на уровне **60 с** (`enforceMinRoundWithBots`) с окном ожидания ИИ после всех людей по умолчанию 30 с (и не менее 60 с с начала раунда).
- Каталог харнессов использует `deliveryMode: 'mcp'` для `claude` и `codex`, и `deliveryMode: 'file'` для `agy` с очисткой `workDir` после каждого раунда (по требованию `UC-2`).

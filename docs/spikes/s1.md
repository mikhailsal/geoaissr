# Spike S1: Launching AI harnesses (`claude`, `codex`, `agy`), MCP, isolation and 3×5 concurrency

Date: 2026-11-13
Goal: verify headless launch of the three local CLIs (`claude`, `codex`, `agy`), image delivery through MCP or restricted local files, isolation from the internet/filesystem/commands, and stability when running 3 bots simultaneously for 5 consecutive rounds (a 3×5 matrix).

## 1. Verified versions and launch flags

- `claude` (`2.1.323 (Claude Code)`):
  - Default model: `haiku`, reasoning `--effort <low|medium|high>`.
  - Image delivery: `mcp` (in memory via `image/jpeg` content blocks).
  - Isolation flags: `--mcp-config <cfgPath> --strict-mcp-config --tools "" --allowedTools "mcp__geo__*" --permission-mode bypassPermissions --setting-sources "" --no-session-persistence --disable-slash-commands --output-format json`.
- `codex` (`codex-cli 0.167.0`):
  - Default model: `gpt-6-luna`, reasoning `-c model_reasoning_effort="<low|medium|high>"`.
  - Image delivery: `mcp` (in-memory via `mcp_servers.geo`).
  - Isolation flags: `codex exec -m <model> -c web_search="disabled" -c features.apps=false -c features.shell_tool=false -c mcp_servers.geo.command=... -c mcp_servers.geo.args=... -c mcp_servers.geo.env.*=... -c mcp_servers.geo.tools.<tool>.approval_mode="approve" -s read-only --skip-git-repo-check --ephemeral --ignore-user-config --ignore-rules --json -C <workDir> -`.
- `agy` (`1.5.8`):
  - Default model: `gemini-3.8-flash-low`, reasoning `--effort <low|medium|high>`.
  - Image delivery: **`file`** (an ephemeral per-round `workDir`, deleted after the round ends). When `mcp` mode is attempted, `agy` dumps binary blocks to a system directory, which requires reading a file; `file` mode in `workDir`, combined with a `PreToolUse` hook, solved both vision and strict isolation at once.
  - Isolation flags: `--print=<prompt> --model <model> --effort <low|medium|high> --sandbox --disable-slash-commands --settings <workDir/settings.json> --output-format json` + the plugin `.agents/plugins/geo/{plugin.json, mcp_config.json, hooks.json, guard.ts}`.
  - `PreToolUse` hook (`guard.ts`): allows only the MCP tools `mcp_geo_geo_*` / `call_mcp_tool` (`geo_geo`) and reading (`read_file` / `view_file`) strictly inside `realpathSync(workDir)` with `.agents/` excluded; rejects shell, web search, third-party MCP and files outside `workDir`.
  - Note on `agy models`: without CLI authorization the `agy models` command returns `Please sign in to view available models`, so the adapter tries `agy models` and, on error, safely falls back to the list from `harnesses.json`.

## 2. Isolation check (canary tests)

Verified with web search disabled and canary targets (`uname -a`, the file `/tmp/geoaissr-s1-canary.txt`):

- `agy` in `file` mode + `guard.ts` successfully read the image in `workDir` and rejected attempts to read `/tmp/geoaissr-s1-canary.txt` and to run `uname -a`.
- `claude` with `--tools ""` and `--strict-mcp-config` has no built-in shell/FS/web tools other than `mcp__geo__*`.
- `codex` with `-s read-only`, `web_search="disabled"`, `features.shell_tool=false`, `--ignore-user-config --ignore-rules` works strictly through `mcp_servers.geo`.

## 3. Single-round and 3×5 matrix results

A single full round (call chain `observe` → `submit_guess` → `look` → `move` → `submit_guess`):

- `claude` (`haiku`, `low`, `mcp`): full round **9.9 s**, first `submit_guess` in **3.8 s**.
- `codex` (`gpt-6-luna`, `low`, `mcp`): full round **20.8 s**, first `submit_guess` in **11.1 s**.
- `agy` (`gemini-3.8-flash-low`, `file`): full round **50.8 s**, first `submit_guess` in **25.6 s**.

Parallel matrix of 3 bots × 5 rounds (15 runs per harness):

| ------------------------------ | ---------- | --------------------------: | ------------------------------------ | ----------------- |
| `claude` (`haiku`, `low`)      | `mcp`      |     **15/15** (`[5, 5, 5]`) | **4.5 – 6.1 s** (`4526–6138 ms`)     | —                 |
| `codex` (`gpt-6-luna`, `low`)  | `mcp`      |     **15/15** (`[5, 5, 5]`) | **10.4 – 21.8 s** (`10355–21794 ms`) | —                 |

## 4. Conclusions for the architecture

- All three harnesses work reliably when 3 bots run in parallel for 5 consecutive rounds, with no host file leakage and no network access.
- The minimum round time limit when AI is present in the lobby settings is justified at **60 s** (`enforceMinRoundWithBots`), with an AI waiting window after all humans of 30 s by default (and no less than 60 s from the start of the round).
- The harness catalog uses `deliveryMode: 'mcp'` for `claude` and `codex`, and `deliveryMode: 'file'` for `agy`, with `workDir` cleanup after every round (per requirement `UC-2`).
